# 最小工作区示例

这个目录只演示输入素材的组织方式，不包含任何真实学校资料、教材或真题。

```text
minimal/
└── 输入素材/
    └── 示例科目/
        ├── 本校考试重点.md
        └── 教材摘录.md
```

实际使用时，把“示例科目”换成你的科目名，把示例文件替换成你自己学校的考试重点和有权使用的教材资料，然后运行：

```bash
python <技能目录>/skills/medagentwork/scripts/init_workspace.py <工作区> --subject <科目>
```

考试重点是输入，不是固定写死在 skill 里的内容。换一所学校时，只需更换输入重点，仍使用同一套题库、复习资料和质量门禁流程。
