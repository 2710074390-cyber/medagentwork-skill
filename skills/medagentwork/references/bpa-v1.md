# BPA v1.0 — 教师重点蓝图版复习资料生成规则（可执行摘要）

> 适用：**任何有「教师重点 / 复习大纲 / 锚定清单」输入的复习资料批次**。
> 性质：HC-20 的落地细则；与 `references/medreview.md`、`references/hard-constraints.md` 同时生效。
> 全文方案（含证据基础与评估标准）：工作区 `docs/教师重点蓝图版_生成规则_v1.0.md`。

## 0. 强制路由（先判断）

| 输入 | 走哪条路 |
|---|---|
| 有教师重点 / 复习大纲 / 锚定清单 | **必须走 BPA v1.0**（本文件）；不得只按教材目录平铺 |
| 无教师重点，只有教材/讲义 | 走 medreview.md 的教学计划版流程（D1–D5），不走本规则 |

判定为 BPA 后，**教师重点原文是范围契约**：输入的 N 条逐条覆盖，不因权重低而删。

> 视觉/排版：结构按本文件；字体、配色、卡片/表格/封面、打印与 Obsidian 基线以 `references/review-visual-spec.md` 为准。

## 1. 自适应结构

按输入素材、教学层级和知识类型组织科目、模块和考点，按学习价值选用蓝图、摘要、对比表、因果链、决策树、案例和回忆题，不规定固定区块、顺序、数量或卡片字段。疾病按适用性讲清识别、检查、鉴别、处理和安全边界；机制讲清关键因果；解剖与操作讲清结构、步骤及风险；分类标准讲清依据、界值和适用条件。自测答案须可检索。

每个知识点确定一处主讲位置，讲透所需事实、判断条件和安全边界；其他位置只保留必要提示及可定位的主讲位置引用。逐条原文锚点、必要禁忌、关键数字和自测可简短重申，不得重复堆字。

## 2. 教师重点落点

每条单独设置 `📌 重点原文（第X条）：` 落点，逐字保留输入原文及全部数值、时间窗、界值、并列与禁止结构，条号以输入锚定清单编号为准。可在同一知识点合并多条，但锚点须一条一行，不包 `<b>`；不得写成 `第26、27条`。其他字段标签按导出兼容要求处理。

## 3. 原文与补写分离

教师只提供主题名时，锚点原样照录主题，另设「教材补写」或「其他来源补充」，注明可核实来源和真实页码，不把补写拼成教师原文。无法核实则标记待核实并在交付说明列出，不得编造；主体、条件和事实的完整解释放在主讲位置。

## 4. 事实与来源纪律

- 来源优先级：教师重点原文 > 教学大纲/课表 > 教材 > 题库/讲义。
- 数值冲突：以教材为准并显式标注冲突；教师明确给出的考试口径保留教师值。
- 页码只引用原文真实标注；全篇同一页码视为占位（HC-10）→ FAIL。
- 教师重点有、教材无 → 保留并标"教师补充"。
- 任何删除/合并写进 CHANGELOG，理由只能是 duplicate / out_of_scope / error / merge。

## 5. 记忆装置

对比表、因果链、决策树、一页纸及检索题按知识类型和学习价值选择，不强制每模块配额；不存在的因果关系或不适用的鉴别不强造。

## 6. 门禁与验收

```bash
# 覆盖门禁（必跑，必须 PASS）
python {SKILL}/scripts/check_keypoint_coverage.py \
  --keypoints "输入素材/{科目}/{科目}_教师重点_锚定清单_{date}.md" \
  --md "{交付MD}"

# 结构自检（历史 BPA 产物或兼容检查；不阻断按自适应结构生成的新资料）
# 当前资料的详细度与适用质量阶段门禁以 `check_review_detail.py` 及质量策略为准
```

**通过线**：教师重点条目覆盖 100%（按输入 N 条计）+ 带单位硬事实缺失 0 + 落点行内事实缺失 0。历史产物可继续报告固定模块/区块/题数结果，但不作为新资料的通用结构准入条件。

来源页码、RAG chunk、题库 qid 只记录可核实信息；无法核实时标记待核实并在交付说明列出，不得虚构，也不得以来源审计通过替代内容覆盖或详细度门禁。

**人工抽检（3-10-30）**：每模块抽 3 张卡遮住正文只读锚点；每科抽 10 个数字回教材；30 秒盲读一页纸能否复述 4/5 个必考点。

## 7. 交付形态（2026-10-22 起）

| 项 | 规则 |
|---|---|
| 交付 | **仅 MD**。Obsidian 可见目录：`Obsidian产物/教师重点蓝图版/{科目}_教师重点蓝图版_主复习资料.md` |
| 工程副本 | `复习资料/{科目}教师重点版/{科目}教师重点版_BPA_主复习资料.md` |
| PDF | **人工从 Obsidian 导出**，管线/脚本禁止生成；站点用人工导出的 PDF |
| HTML | **不再产出**（复习资料 HTML 已下线）；不得为交付而生成本地 HTML 预览 |
| 视觉基线 | 可选 `assets/review-visual.css`（Obsidian CSS 片段/打印基线）；不是交付物，视觉规范见 `references/review-visual-spec.md` |
| 过程产物 | 覆盖矩阵/ledger/自检报告放 `中间产物/{batchID}/`，**不进交付 MD** |

## 8. 反模式（出现即返工）

| 反模式 | 表现 |
|---|---|
| 覆盖=提及 | 正文提一句就算覆盖，锚点仍是主题名 |
| 矩阵=自证 | 全绿但列值是模板话，没有 `n/n` 具体数字 |
| 模板漂移 | 同一册内三种标题体例 |
| 深度=堆字 | 长段落代替机制链与鉴别轴 |
| 流程残留 | 交付物出现 `batch0xx`、`A 部分`、自检报告 |
| 编造来源 | 虚构页码、RAG chunk、题库 qid |
