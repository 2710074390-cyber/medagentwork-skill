# BPA v1.0 — 教师重点蓝图版复习资料生成规则（可执行摘要）

> 适用：**任何有「教师重点 / 复习大纲 / 锚定清单」输入的复习资料批次**。
> 性质：HC-20 的落地细则；与 `references/medreview.md`、`references/hard-constraints.md` 同时生效。
> 全文方案（含证据基础与评估标准）：工作区 `docs/教师重点蓝图版_生成规则_v1.0.md`。

## 0. 强制路由（先判断）

| 输入 | 走哪条路 |
|---|---|
| 有教师重点 / 复习大纲 / 锚定清单 | **必须走 BPA v1.0**（本文件）；不得只按教材目录平铺 |
| 无教师重点，只有教材/讲义 | 走 medreview.md 的教学计划版流程（D1–D5），不走本规则 |

判定为 BPA 后，**教师重点原文是范围契约**：125 条就是 125 条，一条不能少，也不因权重低而删。

## 1. 结构骨架（不可裁剪）

```
科目层（≤2 页）
├─ 使用指南 + 图例（🔴🟡🟢、卡片 ID 规则）
├─ 科目蓝图：模块 × 权重 × 卡片 × 题型（一张表）
├─ 三条阅读路径：30 秒 / 3 分钟 / 30 分钟
├─ 五个记忆主轴
├─ 十个高频陷阱（每条 ≤1 行）
└─ 疾病谱系总览 + 跨模块概念地图（各 1 张 ASCII）

模块层（每模块 1+7，顺序固定）
├─ 1 封面：权重｜题型｜卡片数｜谱系位置｜三个题眼｜阅读时长
├─ 2 🧩 前置知识检查（3–5 问）
├─ 3 🎯 30 秒摘要（5 条，每条 ≤30 字）
├─ 4 📋 考点卡（八行字段，见 §2）
├─ 5 📊 对比速查（2–4 张表，每表 3–5 列）
├─ 6 🔗 因果链（1 张，5–9 节点）
├─ 7 🌳 决策树（1 棵，首分支=关键鉴别轴）
└─ 8 📌 一页纸（6 格）+ 🔄 主动回忆（8–12 题）

附录五件套：页码索引 / 术语同义异名 / 口诀 / 数字锚 / 主动回忆答案
```

## 2. 卡片八行（顺序固定）

```text
#### 🔴 K-M{nn}-{nnn}｜{考点名}（教师重点第X条｜P###）

📌 重点原文（第X条）：{逐字照录；含全部数值/时间窗/并列/禁止结构；单读可答}

<b>🎯 一句话题眼</b>：{≤40 字，看到什么→想到什么}
<b>🧬 为什么</b>：{2–5 行，正常→异常；分类记忆型写"不适用"}
<b>🔗 机制链</b>：{A→B→C，5–9 节点；🔴 卡建议写}
<b>⚖️ 鉴别</b>：{与 1–3 个最易混疾病；给鉴别轴，不给完整疾病描述}
<b>🚨 红线</b>：{禁忌/急症/必须立即处理；无则写"无"}
<b>🩺 下一步</b>：{首选检查/确诊金标准/首选治疗，1–3 条}
<b>🔄 自测</b>：{2–3 问，产出型；答案见附录五}
```

**格式硬约束**

- 锚点行必须 `📌` 开头、**不包 `<b>`**（`check_keypoint_coverage.py` 只认 `^\s*📌\s*重点原文（第X条）`）。
- 其余字段标签一律 `<b>` 开头，避免行首 emoji 被渲染器误判为 callout。
- 一张卡可合并多条重点，但**锚点必须一条一行**；禁止写成 `第26、27条`。

## 3. 锚点自足五规则（BPA 的核心增量）

1. **主体完整**：疾病/结构/操作 + 关键限定（部位/人群/分期/条件）。
2. **事实齐全**：该条全部数值、时间窗、剂量、百分比、分级界值、并列项、禁止结构落在同一行。
3. **不是主题名**：`XX 的病因及治疗原则`、`XX 的临床表现` 一律不合格，必须回源补足。
4. **可单读**：遮住正文，只读锚点，能回答"是什么、关键数字、有什么禁忌"。
5. **可回源**：锚点后标 `（第X条｜教材P###）`；无页码标注的条目不虚构页码。

**主题名条目处理**：回源到教师重点正文 / 教材，补足后用 `——①…②…③…` 接在原文后；补不出就标 `ambiguous` 并在交付说明里列出，**不得凭印象编造**。

## 4. 事实与来源纪律

- 来源优先级：教师重点原文 > 教学大纲/课表 > 教材 > 题库/讲义。
- 数值冲突：以教材为准并显式标注冲突；教师明确给出的考试口径保留教师值。
- 页码只引用原文真实标注；全篇同一页码视为占位（HC-10）→ FAIL。
- 教师重点有、教材无 → 保留并标"教师补充"。
- 任何删除/合并写进 CHANGELOG，理由只能是 duplicate / out_of_scope / error / merge。

## 5. 记忆装置（每模块必须有的最小集）

| 装置 | 数量 | 规则 |
|---|---|---|
| 对比表 | 2–4 张/模块 | 首列是鉴别轴，每格 ≤20 字 |
| 因果链 | 1 张/模块 | 5–9 节点，箭头标因果 |
| 决策树 | 1 棵/模块 | 首分支=关键鉴别轴，每层 ≤3 分支 |
| 一页纸 | 1 张/模块 | 3 必考 + 2 易混 + 1 红线 |
| 检索题 | ≥8 题/模块 | 产出型（填空/解释/对比/下一步/病例） |

## 6. 门禁与验收

```bash
# 覆盖门禁（必跑，必须 PASS）
python {SKILL}/scripts/check_keypoint_coverage.py \
  --keypoints "输入素材/{科目}/{科目}_教师重点_锚定清单_{date}.md" \
  --md "{交付MD}"

# 结构自检（本工作区脚本，见 中间产物/bpa_v1/selfcheck.py）
# 7 模块 × 8 区块、卡片字段、自测数量、附录五件套
```

**通过线**：条目覆盖 100%（125/125）+ 带单位硬事实缺失 0 + 落点行内事实缺失 0 + 每模块 8 区块齐全 + 每模块 ≥8 题。

**人工抽检（3-10-30）**：每模块抽 3 张卡遮住正文只读锚点；每科抽 10 个数字回教材；30 秒盲读一页纸能否复述 4/5 个必考点。

## 7. 交付形态（2026-10-22 起）

| 项 | 规则 |
|---|---|
| 交付 | **仅 MD**。Obsidian 可见目录：`Obsidian产物/教师重点蓝图版/{科目}_教师重点蓝图版_主复习资料.md` |
| 工程副本 | `复习资料/{科目}教师重点版/{科目}教师重点版_BPA_主复习资料.md` |
| PDF | **人工从 Obsidian 导出**，管线/脚本禁止生成；站点用人工导出的 PDF |
| HTML | **不再产出**（复习资料 HTML 已下线）；不得为交付而生成本地 HTML 预览 |
| 过程产物 | 覆盖矩阵/ledger/自检报告放 `中间产物/{batchID}/`，**不进交付 MD** |

## 8. 反模式（出现即返工）

| 反模式 | 表现 |
|---|---|
| 覆盖=提及 | 正文提一句就算覆盖，锚点仍是主题名 |
| 矩阵=自证 | 全绿但列值是模板话，没有 `n/n` 具体数字 |
| 模板漂移 | 同一册内三种标题体例 |
| 深度=堆字 | 长段落代替机制链与鉴别轴 |
| 流程残留 | 交付物出现 `batch0xx`、`A 部分`、自检报告 |
| 编造来源 | 虚构页码、RAG chunk、题库 qid |
