# 硬约束全集（HC / D / R）— MedAgentWork 规则底座

> 本文改编自原项目 SOUL.md。所有角色共享认知。每条约束背后是一次真实事故——**教训不可回退**。

## 共享人格约束

### 医学专业性
- 题目内容必须基于已发表的医学教材/指南，不编造
- 使用标准医学术语（MeSH / ICD-10 / 中华医学会指南术语）
- 证据等级标注：A（指南/系统综述）> B（RCT）> C（病例报告）> D（专家意见）

### 工程纪律
- 先读手册再操作——工具路径、门禁规则全在 references/
- 不尝试访问被阻断站点，优先用国内镜像（按需）

### 交接规范
- 每个角色只读写自己负责的目录（见 runbook.md 目录表）
- 产出文件命名含 batch 号
- 追溯日志必须记录修改依据
- GoldenSet 由用户手动签收，角色不直接写入

### Tone & Communication Style
- 中文优先，结构清晰
- 医学内容：精确术语 + 证据等级
- 交接内容：结构化 JSON + 表格
- 精炼不啰嗦，先结论后细节

## 角色速查

## HC-20 教师重点原文锚定与逐条覆盖（2026-10-18 新增 · Agent 5 主责 · 不可违反）

> 驱动缺陷（batch039 实证）：教师重点原文第15条「突发性聋应尽早进行听力学检查和专科评估，可在发病**2周内**考虑糖皮质激素初始治疗；恢复不完全者可在发病**2～6周**评估鼓室内糖皮质激素挽救治疗」，在复习资料里被概括成「耳科急症，激素一线」——**两个时间窗与"听力学检查时机"全部丢失**。
> 根因：AI 默认走「理解→概括→重组」，概括那一步即是信息丢失点。正确路径是「原文→逐条覆盖→展开」。

- **定性**：教师重点/复习大纲 = **权威范围契约（下限）**，不是"参考素材之一"。Agent 5 的输入来源优先级中，**教师重点原文高于上游备考复习资料**（备考资料是二手概括，只能增强，不得替代逐条覆盖）。
- **三条硬动作（有教师重点输入时强制）**：
  1. **逐条覆盖**：交付前产出 `中间产物/{batchID}/{科目}_教师重点覆盖矩阵.md`（过程产物，**严禁写入交付 MD**），「未覆盖 / 部分覆盖」行数必须为 0；
  2. **原文锚定**：重点条目的数值、时间窗、分级/分期界值、剂量、百分比、比例、专业术语、并列（顿号/分号）与禁止（严禁/不宜/不应/不能）结构，以**原文字面**出现在对应考点内，强制落点行 `📌 重点原文（第X条）：{照录原文关键句}`；
  3. **来源标记**：来自教师重点的考点加锚点 `（教师重点第X条）`。
- **条号基准（2026-10-19 加固）**：`第X条` 一律取 **`--keypoints` 文件的连续编号**（多来源时以编排者下发的「教师重点锚定清单」第四节编号为唯一基准）。来源文档自身标号常有**跳号/重号**（batch040 实证：源①缺 13、37，78 与 86 各重复一次），**禁止直接沿用印刷标号**——否则落点整体错位（batch040 返工重编 72 行）；锚定清单每行尾部以 `〔源X原标号N〕` 供倒查。落点行正文须**逐字照录该条原文**（全部数值/时间窗/界值/百分比/并列与禁止结构须完整落在该行内）。
- **冲突裁决**：**原文锚定 > 原创性**。行为约束"不逐字复制任何单一来源"仅约束教材正文的叙述性文字，**不适用于教师重点条目**——教师重点是范围与强调的唯一权威载体。
- **机械化门禁（HC-12 扩展）**：`python {SKILL}/scripts/check_keypoint_coverage.py --keypoints <教师重点原文> --md <主复习资料 MD> [--allowlist <文件>]` → 数值/时间窗类硬事实缺失 → **FAIL，退出码 1 → 回退 Agent 5 补写，不得放行**；无教师重点输入的批次 → 显式 `SKIPPED`（退出码 2），**不视为通过**。门禁A5 与终审前由编排者执行。
- **规则文本**：完整 D0 段、V17 自检见 `references/prompts/Agent5_MedReview_Prompt.md`；**BPA v1.0 生成规则见 `references/bpa-v1.md`（有教师重点输入时强制，2026-10-22 起生效）**；执行细则见 `references/medreview.md` 与 `references/runbook.md` §3。

## HC-21 发布最新性契约（2026-10-19 新增 · 编排者主责）

> 驱动事故：新产物部署到生产后几分钟，被另一次来源更晚的部署顶掉 → 线上回到旧版；另叠加一处「半更新」：数据数组加了一条，硬编码的「N 科」文案没跟着改。

- **单一事实源**：产物只认唯一源（Git 远端 / 发布通道）。发布前必须 fetch，且 **behind=0 且 ahead=0**；`ahead>0`（未 push）默认**拒绝发布**，先推。
- **发布后置校验（不可跳过）**：
  - **L1 本地**：页面/索引里的统计数字（N 科 / N 题）与数据数组长度一致；每条资源路径在仓库内存在；
  - **L2 远端**：线上条目数、统计数字集合、资源路径与本地一致（防「卡片没上线」）；
  - **L3 最新部署**：线上最新部署的来源 == 本次提交（防被更晚的部署顶替）。
  - 任一 FAIL → 视为发布失败/被顶替 → 立即告警并重部署；**禁止用旧内容覆盖**更新的线上版本，应先合并再发布。
- **文案与数据同源（同一提交内）**：新增/下线任一条目，必须同时改 ① 数据数组；② 分区大标题「N 科」；③ 分区副标题；④ 页面统计数字。缺一即半更新。
- **并发发布**：同一发布窗口只允许一个发布者；线上出现更新的部署时先合并。
- **适用范围（分享版）**：**本 skill 不包含站点部署能力**（无 `check_site_freshness.py`、无部署脚本），此条只在你自行接入发布通道时按上述三道闸执行；纯本地交付（MD/PDF 人工导出）不适用。

## HC-22 真题检索与双族配额（2026-10-20 新增 · 2026-10-26 修订）

> 从题库批次起：约 **1/5 考研真题 + 1/5 执业医师真题**；检索不到就**减量或不插入**，用原创补齐；教师重点优先于凑比例。押题卷暂不适用本配额。

- **配额按来源族结算**，不按单个来源：考研族；执业医师族（族内**印刷版真题与公开题库均可直接入选**，同等相关时印刷版真题轻微优先，但不强制先用完）。
- **批次启动（编排者）**：产出逐题 `source_id / family / tier / keypoint_refs / answer_confidence / license / mode` 的候选计划；`quota_status` 取 `met`｜`reduced`（按可用量减量）｜`cancelled`（无候选取消该族）｜`disabled`。
- **`reduced` / `cancelled` 不阻断批次**，但必须保留 `reason`（`no_candidate` / `candidates_exhausted` / `keypoint_or_module_limit`）与检索日志，**禁止用无关题凑数**，缺口由原创补齐并在批次报告写明。
- **答案可信**：只有 `answer_confidence=high/medium` 的题可入选，`low` 一律不插入；印刷答案与解析冲突时以**原书印刷答案**为准。
- **真题三处标注（缺一不可）**：① 元数据（来源 + 年份/卷次 + `mode=原题|改编` + `answer_confidence` + `license`）；② 溯源锚点 `[源:…]`；③ 每题 `keypoint_ref`（HC-20 统一锚定清单编号）。
- **MedGen 侧**：只插入计划中 `selected` 的题；保留原题干/选项/答案/数值；**不得把改编题标成原题**；配套质检维度（D21）对引用题 100% 比对源，`medium` 答案 100% 抽检。
- **终审门禁**：比例/答案/重复/覆盖/license/溯源任一 FAIL → **halt**，不得绕过；比例按**族**结算（15%–25%）。
- **适用范围（分享版）**：`real_question_cli.py` 与真题语料**不随本 skill 分发**（依赖用户自备真题）。无自有真题时按 HC-18 的降级模式处理：跳过 pick、`check` 显式声明降级、报告留痕 `degraded: true`，并在批次报告写明「该批无真题配额兜底」。

## HC-23 真题语料工程（2026-10-22 新增 · 非批次内动作）

> 把扫描册真题转成可检索的题目级索引。语料跑一次、长期复用；**批次只读索引，不在批次内跑 OCR**。

- **原始素材只读**，落在工作区之外亦可，用环境变量/参数指定目录。
- **OCR 引擎按版式分流（实测结论，不得随意更换）**：
  - **单栏册** → 本地 OCR 引擎（离线、批量、断点续跑）。同一册用版面还原大模型会整行吞掉「【答案】」行，故单栏册**禁止**用版面还原通道；
  - **双栏册** → 必须用**按版面还原段落的引擎**。常规 OCR 检测器会把左右栏并成一条长行（题目与答案区同时污染），无法还原；版面还原通道会丢少量选项（约 10%），由质量门禁拦截，**宁缺毋滥**。
- **流水线三段（可断点重跑）**：清点 → OCR（分通道缓存，缓存不入库）→ 解析 → 去重入库。
- **解析质量门禁（每次重建后必须看报告，按通道分别判定）**：单栏册单册有效率 ≥95%、`no_answer`=0、`bad_options`≤2%；双栏册有效率 ≥70%（版面还原通道已知损耗）。任何一项不达标 → **先修解析规则再重跑，禁止手工挑题绕过**。
- **版面规则（改动需回归全册）**：单栏同行选项／单栏分行选项／双栏／共用题干（A3·A4 病例组，题号在每个病例内从 1 重排）／共用备选答案（B1 组，选项只印一次）／册末「参考答案与解析」区（题号+字母回填）。

## HC-26 复习资料详细度契约（2026-10-27 新增 · Agent 5 主责）

> 驱动缺陷：旧版教师重点版 85 张卡平均正文仅 377 字符，47 张掌握级卡**没有一张**能同时回答「怎么认/怎么查/怎么治/和谁鉴别」；模块里 0 案例、0 展开区——读者读完仍需另找教材。

- **定性**：详细度不是字数，而是「读一遍后能否独立完成临床推理与应试判断」。字数只是下限；**槽位完整、信息单元密度、可检索自测**才是通过条件。
- **三模式**：`teacher_keypoint`（有教师重点/大纲）｜`course_schedule`（周/讲/课时）｜`module`（常规）。有教师重点时 HC-20 逐条覆盖**先于**详细度展开，不得用概括替代原文。
- **卡片九槽位**：`🎯 定位`/`🧬 机制`/`👁 识别`/`🔍 诊断`/`🩺 处置`/`⚖️ 鉴别`/`🚨 易错`/`🧠 记忆钩子`/`🔄 自测`（掌握级另加 `🏥 案例`）。
- **量化下限（release）**：掌握 ≥900 字符且 ≥12 信息单元；熟悉 ≥550 / ≥7；了解 ≥250 / ≥4；掌握级 >3200 字符必须拆分。每句须提供事实/机制/决策规则/鉴别点之一。
- **模块八块 / 课程安排八块**：见标准全文；模块 callout ≥4、展开区 ≥2。
- **机械化门禁**：`python {SKILL}/scripts/check_review_detail.py --md <主复习资料 MD> --mode auto --profile release_teacher_keypoint`；正式发布必须 PASS，报告落 `reports/validate/review_detail_*.json|md`。
- **交付形态**：模块可分片生成，但**交付物只能是一份合并后的 MD**（附录随合并写回）；门禁只对合并后的文件运行。
- **完整标准**：`references/review-detail.md`。
